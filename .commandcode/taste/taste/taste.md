# Taste
- The user's local device has no PHP or Composer — the PHP runtime exists only on the shared hosting. Never run `php artisan`, `composer`, or `phpunit` locally; write files by hand instead of using generators (e.g. hand-craft migrations following existing naming conventions) and hand the post-deploy commands (`php artisan migrate --force`, `php artisan test`) to the user to run on the hosting. Confidence: 0.9
- Deploys the app to shared hosting: build self-contained deployment zips that include `vendor/` (host has no composer) and `.env`, while excluding `.git`, `node_modules`, and runtime artifacts (logs, framework cache/views/sessions). Name zips per target (e.g. `<app>-hosting.zip`) in the project root. Confidence: 0.8
- Zip exclusions like `storage/framework/views/*` also strip the empty directory entry itself; extracting such a zip on the hosting leaves no `storage/framework/views` and Laravel dies with "Please provide a valid cache path." Deploy zips must retain the `storage/framework/{cache/data,views,sessions}` and `bootstrap/cache` directory skeletons (placeholder files or dir entries) — verify with `unzip -l | grep storage/framework` before handoff. Confidence: 0.85
- The hosting's default CLI PHP is 8.3 while composer dependencies require >= 8.4, so plain `php artisan` fails with a Composer platform check; the user runs the alt-PHP 8.4 binary instead (`PHP84=/opt/alt/php84/usr/bin/php; $PHP84 artisan migrate --force`). Hand off post-deploy commands in that prefixed form. Confidence: 0.8
- Laravel + Filament + Pest codebase. It ships agent skill files under `.agents/skills/` (`laravel-best-practices`, `pest-testing`); activate/consult the relevant skill rules before code changes (e.g. read `rules/migrations.md` before touching foreign keys/schemas). Confidence: 0.7
- Feature tests exercise admin behavior through the API endpoints (`Api/V1/Admin/*Controller`) — the established pattern, since Filament table actions aren't exercised by the existing Livewire tests. Cover admin-panel changes by testing their API equivalent. Confidence: 0.6
